## Production env note (for after deploy)
Backend uses CORS_ORIGINS and FRONTEND_URL (email links). For production these must include `https://giguiya.it`. These are USER-owned custom secrets (Secrets tab) — the deployer cannot set them. Set them before/at the deploy that goes live so email links and CORS are correct for the custom domain.

## Custom domain (giguiya.it, registrar Aruba.it) — after the app is live
1. Publish succeeds first → app gets default URL `<app>.emergent.host` (always works, no DNS).
2. Deployment Panel → Domains → add `giguiya.it`. The panel shows the exact DNS records to create.
3. At Aruba.it DNS, create the shown records verbatim (typically a CNAME/A for the hostname + a TXT/validation record). Frontend is Cloudflare-served, so this attaches as a Cloudflare custom hostname.
4. Wait for DNS propagation + SSL issuance (can take minutes to a few hours). Verify with the Domains tab status.
